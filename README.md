## ✨ Sobre o projeto

Este projeto consiste em uma **one page completa para a Pizzaria Pavão**, localizada no Jardim São Luís, em São Paulo - SP.

A proposta foi criar uma experiência digital que combine:

- 🍕 Apresentação da pizzaria
- ✨ Identidade visual sofisticada
- 📋 Cardápio interativo
- 📱 Experiência mobile-first
- 💬 Pedidos diretamente pelo WhatsApp
- 📍 Informações de localização
- ⭐ Avaliações
- 📝 Formulário de pedido
- ♿ Boas práticas de acessibilidade
- 🔎 Estrutura preparada para SEO

O design foi desenvolvido tendo como principal referência a identidade visual do **logo da Pizzaria Pavão**, utilizando uma combinação de preto, dourado e creme para transmitir uma estética elegante e marcante.
